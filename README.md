# learn-leaky-config

An exercise repository for [ComputeSphere Learn](https://learn.computesphere.com), *Application foundations*, lesson **2.5.3 Try it: find a secret in git history, then remove it properly**.

A payment key was committed and then removed, but it's still in the history. Find it, then clean the history on your own clone. The key in it is fake; it opens nothing.

Work on your local clone only. Don't open pull requests here.
